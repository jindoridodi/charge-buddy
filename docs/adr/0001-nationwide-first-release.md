# Nationwide first release

ChargeBuddy's first release targets the entire United States rather than a bounded regional pilot. Public charger coverage, search, and trip planning must therefore work nationwide, while clearly exposing missing, stale, or unavailable data instead of implying uniform live coverage.

**Status:** accepted

**Consequences:** The data-import, routing, performance, and acceptance plans must be tested beyond the San Jose sample. A regional demo dataset is useful for deterministic tests but is not sufficient release evidence.
